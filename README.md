# Resim Android
Kotlin Android uygulaması. Galeriden fotoğraf seçin; **Basılı Tut** ile dokunulan renge bağlı alanı seçin veya **Çiz** ile nesnenin çevresini çizin. Seçim dışı beyaza döner. **Kaydet** PNG çıktısı oluşturur.

## APK
GitHub Actions > Android APK > son başarılı çalıştırma > Artifacts > Resim-debug-apk.

Not: Basılı tutma yöntemi renk benzerliği tabanlıdır; karmaşık fotoğraflarda kusursuz yapay zekâ segmentasyonu değildir. Çizim yöntemi elle çokgen maskelemedir.
